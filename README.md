🧬 Breast Cancer Survival Analysis Using SAS
📌 Project Overview
This is a practical SAS learning project focused on breast cancer survival analysis using the METABRIC clinical dataset.
The project is part of my journey to develop practical skills in SAS programming, statistical analysis, and biostatistics.
🚧 Project Status: In Progress
________________________________________
🎯 Objectives
The main objectives of this project are to:
•	Learn and apply SAS programming to a clinical dataset
•	Perform data cleaning and preparation
•	Conduct descriptive statistical analysis
•	Explore survival outcomes in breast cancer patients
•	Apply Kaplan–Meier survival analysis
•	Learn Cox proportional hazards regression
•	Develop reproducible statistical analysis workflows
________________________________________
📊 Dataset
The project uses the METABRIC clinical dataset, containing clinical and pathological information on breast cancer patients.
The dataset contains approximately:
•	2,509 patients
•	39 variables
The raw dataset is not included in this repository. Users should obtain the dataset from its appropriate source and follow the applicable data-use terms.
